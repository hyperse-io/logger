# Logger Stdout Plugin

This plugin is the official standard output plugin for [Hyperse Logger](https://github.com/hyperse-io/logger), designed specifically for Node.js environments. It outputs logs to the terminal (stdout/stderr) in a consistent, structured format, supporting JSON-compatible output for easy log collection and analysis. Ideal for server-side and containerized applications, it ensures your logs are well-formatted, easy to process, and ready for integration with log management systems.

## Installation

```sh npm2yarn
npm install @hyperse/logger-plugin-stdout
```

## Usage

```ts twoslash
// @filename: @hyperse/logger-plugin-stdout/dist/index.d.ts
import {
  createStdoutPlugin,
  StdoutOptions,
} from '@hyperse/logger-plugin-stdout';
import { createLogger, LogLevel } from '@hyperse/logger';

const logger = createLogger({
  name: 'hps-logger',
  thresholdLevel: LogLevel.Verbose,
})
  .use(createStdoutPlugin())
  .build();

logger.info('info message');
```
