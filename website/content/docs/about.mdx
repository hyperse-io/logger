## About Hyperse

Hyperse is an open-source full-stack development suite that provides front-end
components, architecture patterns, and tech solutions. Built with `TypeScript`,
`GraphQL`, and `Node.js`.

## Related Projects

Hyperse is powered by these incredible open source projects:

- [@hyperse/logger](https://github.com/hyperse-io/logger)
- [@hyperse/logger-plugin-console](https://github.com/hyperse-io/logger/tree/main/packages/logger-plugin-console)
- [@hyperse/logger-plugin-stdout](https://github.com/hyperse-io/logger/tree/main/packages/logger-plugin-stdout)
