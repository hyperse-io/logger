Context Merging

The logger automatically merges the context types and values from all loaded plugins. This means that if you have multiple plugins, each defining their own context, the logger will combine them into a single context type and merge their values at runtime.

Logger

  • Logger is a class for constructing customizable loggers.
  • It supports a plugin mechanism, allowing flexible extension of the logging process, including custom log levels, formatting, and output handling.
  • Plugins can be added via the chainable use() method, and the final logger instance is created with the build() method.
